# 考研英语生词整理

日常复习直接用浏览器打开 `output/index.html`，不需要启动服务。
要**上传试卷、摘录外刊或书页、自动识别圈画生词**，双击 `启动生词本.command`
（Windows 用 `启动生词本.bat`），浏览器会打开本机应用（`http://127.0.0.1:8765`）。

## 本机应用：试卷 / 外刊 / 书页都能收词（2026-09-16 新增）

macOS 用系统自带的文字识别与 PDF 渲染，不需要安装任何东西；材料不出本机。

| 场景 | 做法 | 入库后带着什么 |
| --- | --- | --- |
| 真题试卷 | 拍照或上传 PDF，自动识别被圈、被划线的词 | 年份、题型、段落、真题原句、整卷核对链接 |
| 外刊文章 | 选中句子点浏览器小书签「📎 摘录到生词本」，或粘贴段落并填链接 | 原句、释义、来源名称与可点击的原文链接 |
| 原版书 / 教材 | 拍书页上传，或粘贴段落并填书名与章节 | 原句、释义、书名与页码 |
| 练习册 | 同上，来源类型选「其他材料」 | 原句、释义、材料名称 |

收词分两级、刻意收紧：**只有已录入生词的词显示释义**，没录入的词只给原文位置，
想收录就点“加入待整理清单”回工作台补全。

工作台核对后保存的词有两个去处：一是写进 `data/vocabulary_additions.json`，
`python3 main.py` 重新生成复习页面时可看到；二是按 `PersonalCore` 规则生成
“个人词条卡片”，重新生成页面后并入浏览器里已有的**个人词库**（“查词与收词”页），
与你自己收的词按词义去重、共用一套复习。

技术说明见 [vocabulary_app/README.md](vocabulary_app/README.md)；
升级前请先看“更新方法”一节的验证命令。

## 复现如何计算

复现范围为词库中已保存的原句、选项与人工核对补充句，并非全部试卷全文词频。同一原句供多个单词共用时只计一次。

“跨篇复现”表示至少两篇不同材料中出现；“同篇复现”表示同篇至少有两个不同的已录入语境。已核对但未划线的位置也可以作为复现证据。正文、题干与错误选项会标明来源，选项本身不代表正确答案或文章观点。

按明确的原形与词形变化匹配，如 `reinforce/reinforced/reinforces`。不把 `inherit` 与 `inherent` 合并，也不把 `prohibit` 与派生名词 `prohibition` 合并。不同语境的词义可以不同，如 `state` 可以是“状态”，也可以是“国家”。

当前已查见35个跨篇复现词，具体清单以运行生成的 `output/整理统计.json` 为准；新增材料后会自动重新计算。

## 更新方法

1. 上传新截图，或提供截图路径和可确定的试卷年份。
2. 核对划线词，将新记录追加至 `data/vocabulary.json` 的 `entries`；为每条分配独立稳定ID。
3. 保存原始照片到 `images/`，登记 `source_images` 的相对路径及SHA256。相同SHA256的照片不要重复入库。
4. `lemma` 保存用于复现统计的原形；`forms` 仅保存确实同属该词的词形变化。不要把近义词、派生词混入。
5. `example` 与 `translation` 保存完整原句及翻译，`short_meaning` 保存简短语境释义。未划线复现证据可以加入 `additional_evidence` 或 `extra_contexts`。
6. 完形空格写为 `__题号__`，不擅自填答案；仅有一个单词的错误选项保留原选项，不另造句冒充原文。
7. 在项目目录运行：

```powershell
python main.py
```

程序重建总复习页、总完整版、复现页、统计JSON和音频清单，并同步播放器脚本，不覆盖原2017历史文件。刷新浏览器即可查看。

验证命令：

```powershell
python -B -m unittest discover -s tests -v
```

## 美音朗读

总复习、完整版和复现页均可点击“▶ 单词”或“▶ 例句”。简短版播放完整原句；单词按页面词条标题朗读。语速可选0.7至1.5倍，播放中可调速，点击“停止”结束。点击另一条会结束上一条，不叠加播放。完形空格读作 blank，不填答案。

音频由本机 Microsoft Zira Desktop（en-US）合成，格式为22,050 Hz、16位、单声道WAV，保存在 `output/audio/`。加上本次搭配更新后共640段，同一句或词语共用文件。打开HTML即可离线播放，不需要语音插件。旧词音标原样保留，新增音标采用美音；全部音频为美音。旧2017历史文件保持原样，旧词的朗读请在总复习页筛选2017。

更新词库后，以下命令一并更新页面与缺失音频：

```powershell
python main.py --audio
```

仅重建页面仍用 `python main.py`。音频合成需要Windows及Microsoft Zira Desktop美音包；没有该语音时脚本明确报错，不换用其他口音。已生成的音频可复制到其他设备播放，不依赖该设备的语音包。合成语音对个别专有名词、缩写和孤立多音词的读法可能不如人工录音准确。

若显示“音频未能播放”，先确认 `output/audio/` 和 `output/speech.js` 随页面完整保存，再运行上述更新命令。不要单独移动一个HTML文件。

## 背词练习与掌握程度（2026-09-16）

直接打开 `output/背词练习.html`，或从总复习页顶部进入“背词练习”。原236条词汇记录保留；同词同义合并后形成230个学习单元。三个 convert 语境分别练习，同词同义如 deem 共享掌握程度。复现频次仍按原形统计，与掌握程度的词义分组相互独立。

### 每天如何使用

1. 每日新词默认10个，可设置1—100个。“开始今日学习”先安排到期词，再补足新词计划；“只复习到期词”不加入新词。
2. 题目交替采用看英文选中文、看中文选英文。干扰项按词性、互异释义和人工近义词排除表筛选；缺少合适选项时使用翻卡自测。未来尚未审核出题资料的新词也先用翻卡。
3. 不会可点“不认识”，或查看原句提示。数字键1—4也可选答案。
4. 作答后依次显示**文中词义、完整原句和翻译、搭配与用法**。搭配区分“原文搭配”和“补充搭配”，没有适合的搭配则省略。
5. 答对后根据看到答案之前的状态选择“猜对的／不确定”或“确实知道”。首次答对仍为模糊，不能仅凭猜中选项直接升级熟悉。使用提示后最高为模糊。
6. “保存并返回”保留当前题目，下次选择“继续上次练习”。直接刷新也可续练。“结束本轮”显示统计；已选择正确答案但未确认程度时，保守记为模糊。

### 复习间隔

| 状态 | 规则与下一次复习 |
| --- | --- |
| 未学 | 尚未作答，进入每日新词计划 |
| 不认识 | 答错或点击不认识，约10分钟后到期；本轮穿插加练，最多额外两次 |
| 模糊 | 首次答对、猜对或使用提示；次日到期 |
| 熟悉 | 不同日期、两个方向都无提示答对并确认知道，且到期复习通过后进入；之后间隔3、7、14、30、60天，最长保持60天 |

间隔以作答时间加对应天数计算。当天反复答对不会连续推进等级；提前答对不推迟原有到期时间。答错或不确定会回退并重新积累成功记录。以上是本项目的初始学习规则，不能保证某个词在固定天数内掌握；准确性比点击次数重要。

“按文章练习”允许提前复习该文章的旧词，新词仍计入每日计划。词旁“练习此词”和本轮错词回练是主动加练。学习页只有打开时显示到期任务，没有后台通知服务。

### 在生词本里查看状态

简短总复习、全部生词完整版和复现页的词旁显示“未学／不认识／模糊／熟悉”。点击可查看最近练习、下次复习和作答次数，也可把模糊或熟悉词向下调整。向上升级通过练习完成。同词不同义分别记录，未作为独立生词收录的补充语境不会凭空生成掌握等级。

简短总复习和全部生词完整版支持材料、文章、掌握程度、复现条件的组合筛选，保存筛选和滚动位置。隐藏词义自测时点击词义遮盖区域揭示该词。美音与筛选工具栏随滚动保留。

### 保存、备份与恢复

学习事件、每日计划、未完成题目和页面偏好保存在**当前浏览器的 IndexedDB**。几个本地HTML通过同一存储页面 `output/progress-store.html` 共享记录；写入使用事务，降低多页面写入互相覆盖的风险。页面切换和重新获得焦点时更新标签。练习以一轮为单位，建议在一个标签页作答；如果另一个页面已开始新一轮，旧页面提交会提示刷新。

此功能已在Chrome直接打开本地HTML的方式下验证。其他浏览器或应用内浏览器可能限制本地文件的存储；保存失败会在页顶提示，不能把错误提示状态当成已保存。文件访问和浏览器配置的差异意味着换浏览器、换设备、移动路径前仍应备份。

各页面“词库与进度备份”可导出JSON，包含个人收词、学习记录和每日新词计划。导入先检查格式，再确认合并；已有记录保留，相同编号的相同记录不重复计入，编号冲突或非法记录整批拒绝。备份不包含原图、项目原始词库、完整词典和未完成的题目队列；换设备需复制完整项目并导入进度。

项目页面、截图和WAV仍放在D盘；**浏览器的学习记录位于其用户配置目录，可能在C盘**。导出文件的位置由浏览器下载设置决定，可选择保存到本项目的 `backups/`。浏览器清理数据、重置配置或换浏览器不会自动同步，请提前导出。无需登录，也不上传学习记录到云端。

### 后续添加词汇

原词库继续在 `data/vocabulary.json` 维护。学习补充资料在 `data/study_config.json`：

- `entries[id].quiz_gloss`：明确的语境释义，用于出题；`pos`：当前用法词性。
- `collocations`：搭配文字、中文、原文或补充标记。原文标记必须能在保存的原句中找到。
- `aliases`：经核对的同词同义合并关系。已投入学习的ID保持稳定，调整ID或合并关系需要迁移旧进度。
- `confusable_groups`：容易同时成立的近义词组，不互作干扰项。

`study_build.py` 生成学习资料，`assets/study-core.js` 负责复习规则和备份校验，`progress*.js/html` 负责保存，其他脚本负责练习与标签。程序不自动识别新截图，也不会仅凭相同拼写合并不同义项。

更新与验证：

```powershell
python -B main.py --audio
python -B -m unittest discover -s tests -v
node --test tests/study-core.test.js
```

不需要安装Python第三方依赖；Node仅用于规则测试，日常打开网页和生成页面不依赖Node。本次新增搭配美音复用同一Microsoft Zira Desktop声音，合计640段离线音频。


## 离线查词与个人收词（2026-09-16）

双击 `output/查词与收词.html`，或从首页、真题检索进入。输入英文单词或短语，选择年份、题型后查询。查询不自动收词；选择一个释义（可手动修改）、勾选所需原文例句，再点击“加入总复习”。没有例句时也可以只保存词义。词典没有收录时可自行填写核对后的词义；不生成替代例句。

个人词出现在简短总复习、完整版、背词练习；保存多处语境的词也会进入复现页。相同原形与相同释义去重；选择已有义项会补充语境并沿用学习编号。不同文字的释义不能自动判定语义等价，想沿用原词请点“已有义项”。个人新词未核对词性与干扰项，采用双向翻卡自测，并沿用原有间隔复习规则。已有正式词的选择题不变。

通用释义不等于文章中的具体意思；收词前应结合原句核对。译文由使用者手动填写，留空明确标为待补充。新增固定搭配暂不自动生成。正文按句切分，选项和题干保留原样，完形空格不擅自补全。原句来源链接可跳到本地整卷。

词典为 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT许可及来源校验保存在 `data/dictionary/LICENSE.txt` 和 `manifest.json`。当前包含768739个有中文释义的词条，按首字母分为27个本地脚本，首次查词只加载对应部分。音标以来源为准，主要为英音，并未冒充美音；词形关联也需核对。词典条目质量参差，专业义项、生僻词可手动补充或纠正。

原有WAV美音继续离线播放。个人词和例句优先复用已有音频，其余使用浏览器公开的本地英语（美国）语音。浏览器未提供本地美音时会明确提示，绝不自动使用联网声音；此时查词、收词和复习仍可正常使用。

个人词库与学习进度保存在当前浏览器IndexedDB，不写进 `data/vocabulary.json`。共享页面使用同一存储入口；重新获得焦点时刷新。导出JSON包含个人词、所选语境、手写译文及学习记录；旧版仅含进度的备份仍可导入，保留已有个人词。重复导入合并相同记录，非法数据整批拒绝。个人词库上限5000个义项，每个义项30条例句；备份文件上限30MB。换设备或分享自己的收词时，复制完整项目后另行导入备份。浏览器存储与磁盘项目不同，清理浏览器前必须导出。

重新生成页面仍运行 `python -B main.py`，不会清除浏览器个人词库。复建词典需先获取来源CSV和许可文件，再运行 `python scripts/build_dictionary.py CSV路径 LICENSE路径`；正常使用不需要Python、Node或网络。

测试：`python -B -m unittest discover -s tests -v`；`node --test tests/study-core.test.js tests/personal-core.test.js`。源码中 `personal-core.js` 校验合并，`personal-library.js` 并入学习资料，`dictionary*.js` 查询与收词，`personal-review.js` 渲染个人词。既有分享ZIP是生成时的快照，本次修改不会自动改写旧分享包。

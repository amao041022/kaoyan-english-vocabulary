# 2006—2025 考研英语全文题库

## 已保存的内容

20套：2006—2009为分卷前考研英语旧卷，2010—2025为英语（一）。每套包含完形、阅读Text 1—4、新题型、翻译、小作文和大作文。正文、题干、选项、作答说明分别保存。**不包括英语二，也不包含答案解析。**

- `../../images/exam_bank/年份.pdf`：来源网站的整卷PDF，第三方重新排版。
- `../../images/exam_bank/年份.html`：下载时的原始网页快照，仅留作溯源。
- `../../images/exam_bank/年份-figure-1.jpg`：作文配图。
- `年份.json`：可检索结构化文本，每条有稳定ID、题型、位置、原文和网页锚点。
- `年份.md`：供人工/助手阅读的文本；作文配图请查看本地整卷页。
- `年份.pdf.txt`：逐页抽取的PDF文字，辅助核对。
- `年份.source.json`、`年份.figures.json`：来源URL、时间及文件SHA256。
- `manifest.json`：20套题库清单；`验收记录.md`：本次导入检查及限制。
- `../../output/真题检索.html`：离线查词页面；`../../output/exams/年份.html`：含配图的离线整卷页。

## 后续怎样给词

直接发送：`2017年英语一：undermine、eligible、reluctance`。

如果只整理某一篇，发送：`2017年英语一 Text 1：undermine、eligible`。只给年份默认在本题库的英语一/旧卷范围内查询；若实际是英语二，应明确标注并提供原卷。

检索保留同词的多处原文，一词多义分别解释。单独的错误选项只标为“选项”，不能伪装成原文完整例句；完形空格保持 `__题号__`，新题型保持待选状态，不自行补答案。题库不会自动改动生词和熟悉程度。

## 命令行（在项目根目录运行，普通 Python 即可）

```powershell
python -B -X utf8 exam_bank.py --year 2017 --words undermine eligible reluctance
python -B -X utf8 exam_bank.py --year 2017 --section text1 --words undermine --json
python -B -X utf8 exam_bank.py --year 2025 --words "take off" --forms "takes off" "take-off" --json
```

查询词不自动进行宽泛词干推测；默认使用原词及既有生词库明确登记的词形。`--forms` 只用于一个词，需人工确认形态关系。找不到时核对年份、卷别、拼写和原文词形，不编造例句。

JSON结果中的 `example` 是原文连续子串，`paragraph` 保留整段，`start/end` 为子串位置。`pdf_pages` 目前定位到原段开头所在页，跨页段落应在整卷中继续核对；准确位置以 `record_id`、题型、段落及本地整卷锚点为准。切句是保守规则，个别缩写、引号、翻译题编号附近需人工校读。

## 生成与维护

`python main.py` 会更新复习页入口和浏览器检索数据，不联网下载、不改原卷。

`scripts/build_exam_bank.py` 可以从保存的HTML、PDF和配图清单重新抽取全文及整卷页面，依赖 `lxml`、`pypdf`；日常查询只需标准库。请先备份再重建；不要用变化后的网络页面静默替换已登记原卷。来源文件SHA256变化时，程序拒绝继续。

新增生词时沿用现有数据格式，为PDF登记 `source_images`，并保存 `exam_record_id`。生成 `python main.py --audio` 可调用原有美音生成流程。不同语境的释义需分别核对，不能根据相同词形自动继承旧义项。

## 来源与限制

公开来源：[LazyNote 考研真题目录](https://english-exam.lazynote.cn/kaoyan/)。原卷与文本均为第三方整理版，不能视为官方扫描件或已逐字校对的标准答案。

检查发现来源PDF全部缺少作文配图，因此另外保存20张配图，并补入本地整卷HTML；PDF文件保持原样。图片内文字保留在图片中，没有把网站自动生成的图片说明冒充真题文本。英文词句检索覆盖可抽取的卷面文本，图片中文字不参与检索。

已检查20套、9类题型、完形题号与选项、阅读题干与选项、新题型待选材料，比较PDF可抽取词汇与HTML文本覆盖，并抽查既有2017照片例句。尚未逐字人工核对全部试题；若发现个别排版、拼写差异，应回看本地整卷、来源页或用户原图后更正，并记录更正依据。
